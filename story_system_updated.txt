UPDATED STORY GENERATION SYSTEM (WITH TIME + LOCATION)

============================================================
1. GOAL
============================================================
Build a scalable story/script generation website that:
- Uses public domain books
- Uses NLP + rule-based system
- Generates original stories (no copying)
- Supports location + time-based storytelling
- Scales to 1000+ users (free infra)

============================================================
2. DATA SOURCES
============================================================
Use:
- Project Gutenberg
- Internet Archive
- Open Library

Indian content:
- Panchatantra
- Vikram Betal
- Jataka Tales
- Akbar-Birbal
- Tenali Raman
- Tagore / Premchand

Preferred format:
HTML > TXT > PDF

============================================================
3. TECH STACK
============================================================
Frontend:
- React / Next.js (Vercel)

Backend:
- Python (Flask / FastAPI) (Render)

Database:
- Supabase (PostgreSQL)

NLP:
- spaCy (NER, entities)
- NLTK (tokenization, keywords)

Parsing:
- BeautifulSoup (HTML parsing)

============================================================
4. DATA PIPELINE
============================================================
HTML Books
   ↓
Parse (BeautifulSoup)
   ↓
Clean text
   ↓
NLP processing
   ↓
Structured JSON storage

Example:
{
  "text": "...",
  "characters": ["Ram", "Sita"],
  "themes": ["duty", "love"]
}

============================================================
5. NLP ROLE
============================================================
Used for:
- Character extraction
- Theme detection
- Keyword extraction
- Sentence structure

NOT used for full story generation

============================================================
6. STORY ENGINE
============================================================
Components:
1. Character Generator (traits, roles, motivation)
2. Plot Generator (Intro → Conflict → Climax → Resolution)
3. Chapter Generator (300–500 words)
4. Scene Generator (paragraph-level)

============================================================
7. LOCATION + TIME ENGINE
============================================================
Input:
Location: Hyderabad
Year: 1900

Example:
{
  "location": "Hyderabad",
  "year": 1900,
  "environment": ["markets", "palaces", "carriages"],
  "technology": "low",
  "tone": "royal",
  "conflicts": ["politics", "class divide"]
}

Influences:
- Dialogue style
- Transport
- Conflict type
- Lifestyle

============================================================
8. CONTROL SYSTEM
============================================================
- Prevent full story in chapter 1
- Enforce structure
- Avoid repetition
- Maintain state
- Block copying patterns

============================================================
9. ANTI-COPY SYSTEM
============================================================
- Use role-based generation
- Replace names later
- Use diverse datasets
- Add constraints

============================================================
10. SCALABILITY
============================================================
Architecture:
Frontend (Vercel)
   ↓
Backend (Render)
   ↓
Queue System
   ↓
Worker
   ↓
Database (Supabase)

Optimizations:
- Cache outputs
- Preprocess data
- Async processing
- Chunk generation

============================================================
11. EDGE CASES
============================================================
- Overfitting
- Repetition
- Weak structure
- Bias from names
- Timeline mismatch
- Wrong location details

============================================================
12. FINAL PIPELINE
============================================================
User Input (Genre + Theme + Location + Time)
        ↓
Validation
        ↓
Location + Time Engine
        ↓
Character Generator
        ↓
Plot Generator
        ↓
Chapter Generator
        ↓
NLP Cleanup
        ↓
Final Story

============================================================
13. CORE PRINCIPLES
============================================================
- Structure > Model
- Control > Random
- Data quality > Quantity
- Hybrid > Pure AI
